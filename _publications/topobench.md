## A shared framework for topological learning

TopoBench organizes experiments into interchangeable components for data loading, topological transformations, models, and evaluation. This makes it possible to compare approaches across representations such as graphs, hypergraphs, and cell or simplicial complexes.

The project provides implementations, documentation, and reproducibility instructions for researchers building and benchmarking topological learning methods.
