## Reusable vascular geometry

AAA-100 contains 3D models of abdominal aortic aneurysms and surrounding vasculature. Watertight surfaces make the models useful for workflows that require a closed geometric domain, including computational modeling.

The linked release is version 0.1.0. Cite its version-specific DOI when using this release; the concept DOI identifies the dataset across versions. Dataset documentation and usage terms are provided with the Zenodo record.
